# auto-hh

Поиск, отбор и автоотклик на вакансии hh.ru.

> ⚠️ Соискательский API hh.ru отключён 15.12.2025, поэтому отклики выполняются через **Playwright** (браузерная автоматизация). Это нарушает пользовательское соглашение hh.ru и может привести к блокировке аккаунта. Используйте на свой страх и риск, лучше с тестового аккаунта и без агрессивных интервалов.

## Возможности
- Поиск через публичный API hh.ru с фильтрами (анонимно)
- Локальный пре-фильтр: навыки, исключённые слова/компании, ЗП
- **Claude читает ваше резюме** и для каждой пред-отобранной вакансии решает, стоит ли откликаться (score 1–10, объяснение, red flags)
- Для подходящих — Claude пишет персональное сопроводительное на основе описания вакансии и резюме
- Дайджест в JSON с вердиктом, скором и письмом
- Автоотклик через сохранённую сессию браузера (Playwright)
- История: уже видел / уже откликался
- Кэш собранных вакансий за текущую дату — после обрыва не нужно ходить за hh заново

## Установка

```bash
npm install
npx playwright install chromium
cp .env.example .env
```

Положите рядом с проектом `resume.md` (или `.txt`/`.pdf`) — Claude его кеширует и сравнивает с каждой вакансией.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run login` | Открывает Chromium, ждёт ручного логина на hh.ru, сохраняет сессию в `data/browser-profile/` |
| `npm start` | Ищет вакансии, фильтрует, судит Claude'ом, пишет письма, складывает в `data/digest-YYYY-MM-DD.json` |
| `npm run apply` | Поднимает браузер на сохранённой сессии и откликается на всё из последнего дайджеста |

### Флаги CLI

**`npm start` / `node index.js`:**
- `--reset` (или `--fresh`) — перед запуском удаляет `data/history.json`, все `data/digest-*.json`, `data/rejected-*.json` и `data/collected-*.json`. Полный новый прогон с нуля.

**`npm run apply` / `node src/apply-playwright.js`:**
- `--login` — режим логина (то же, что `npm run login`)
- `--limit N` (или `--limit=N`) — обработать только первые N вакансий из дайджеста

## config.json

```json
{
  "search":  { ... },
  "filter":  { ... },
  "apply":   { ... }
}
```

### `search` — параметры запроса к hh.ru
| Поле | Что задаёт |
| --- | --- |
| `text` | Поисковая строка (поддерживает `OR`, `AND`, скобки) |
| `area` | ID региона hh (null = вся Россия) |
| `experience` | Например `between1And3`, `between3And6` |
| `salary` | Минимальная ЗП |
| `currency` | `RUR`, `USD`, … |
| `only_with_salary` | Только вакансии с указанной ЗП |
| `schedule` | `remote`, `flexible`, … |
| `employment` | `full`, `part`, `project`, … |
| `per_page` | Сколько вакансий на странице (≤ 100) |
| `start_page` | С какой страницы начинать (0 = первая) |
| `max_pages` | Сколько страниц обойти, считая от `start_page` |

### `filter` — локальный пре-фильтр
| Поле | Что задаёт |
| --- | --- |
| `requiredSkills` | Список — хотя бы один навык должен встретиться в описании |
| `excludedKeywords` | Слова, при наличии которых вакансия отбрасывается |
| `excludedCompanies` | Компании, которые игнорируем |
| `excludeArchived` | Пропускать архивные вакансии |

### `apply`
| Поле | Что задаёт |
| --- | --- |
| `maxPerRun` | Максимум вакансий в один дайджест |
| `dryRun` | Зарезервировано (не отправлять отклики) |
| `minClaudeScore` | Нижний порог score'а от Claude, всё ниже отбрасывается |
| `coverLetterTemplate` | Шаблон письма-фолбэка, если Claude недоступен. Плейсхолдеры: `{title}`, `{matchedSkills}` |

## Переменные окружения (`.env`)

### Базовое
| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `CONFIG_PATH` | `./config.json` | Альтернативный путь к конфигу |
| `HH_USER_AGENT` | `AutoHH/1.0` | User-Agent для API hh.ru — рекомендуется ставить ваш email |
| `RESUME_PATH` | — | Путь к резюме (`.txt`, `.md`, `.pdf`); без него Claude-судья выключен |
| `APPLICANT_PROFILE` | `опытный разработчик` | Короткое описание-фолбэк, если резюме не задано |
| `REQUEST_DELAY_MS` | `1500` | Пауза между запросами к hh API |
| `DEBUG` | — | Любое непустое значение включает `log.debug` |

### Claude
| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | — | Без него Claude-судья и генерация писем выключены |
| `CLAUDE_MODEL` | `claude-opus-4-7` | Модель для judge и cover-letter |
| `JUDGE_BATCH_SIZE` | `10` | Сколько вакансий в одной пачке отправлять на судейство |
| `COVER_BATCH_SIZE` | `20` | Сколько писем генерировать за один запрос |

### Playwright (`npm run apply` / `npm run login`)
| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `PW_USER_DATA_DIR` | `./data/browser-profile` | Где хранится профиль браузера |
| `PW_HEADLESS` | `false` | `true` для фоновой работы |
| `PW_MIN_DELAY_MS` | `500` | Нижняя граница рандомной паузы между откликами |
| `PW_MAX_DELAY_MS` | `2000` | Верхняя граница |
| `PW_TEST_MODE` | `manual` | `manual` — окно на передний план и ждать ENTER в консоли; `skip` — пропускать вакансии с тестом |
| `PW_TEST_TIMEOUT_MS` | `0` | Таймаут ожидания ENTER в manual-режиме (0 = без таймаута) |

### Зарезервировано / не используется в основном потоке
`HH_CLIENT_ID`, `HH_CLIENT_SECRET`, `HH_REDIRECT_URI`, `HH_ACCESS_TOKEN`, `HH_REFRESH_TOKEN`, `HH_RESUME_ID` — для OAuth-сценария (`src/oauth-server.js`), сейчас не задействованы, т.к. соискательский API закрыт.

## Файлы в `data/`

| Файл | Что в нём |
| --- | --- |
| `history.json` | Какие вакансии уже видели / откликались |
| `collected-YYYY-MM-DD.json` | Кэш страниц поиска, подробностей вакансий, вердиктов Claude и сгенерированных писем за текущую дату — позволяет продолжить после обрыва, не пересудя/перегенерируя то, что уже сделано |
| `digest-YYYY-MM-DD.json` | Подходящие вакансии с письмами |
| `rejected-YYYY-MM-DD.json` | Вакансии, отбракованные Claude'ом, с причинами |
| `browser-profile/` | Профиль Chromium (cookies, localStorage) |
| `apply-dom-*.html` | Дамп DOM, если Playwright не нашёл textarea для письма |
| `app.log` | Лог |

## Замечания

- Селекторы hh.ru со временем меняются — если автоотклик перестал работать, посмотрите `data/app.log` и обновите массивы `respondSelectors`, `submitSelectors` и т.п. в `src/apply-playwright.js`.
- Тесты в вакансии: по умолчанию (`PW_TEST_MODE=manual`) скрипт ставит окно браузера на передний план и ждёт ENTER в консоли — заполняете тест и отправляете отклик руками, после ENTER идёт следующая вакансия. Чтобы вернуть старое поведение, поставьте `PW_TEST_MODE=skip`. Ручной режим работает только при `PW_HEADLESS=false`.
- Лимит откликов в день у hh.ru — ~200; не превышайте.
