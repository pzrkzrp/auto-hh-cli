# auto-hh

Поиск, отбор и автоотклик на вакансии hh.ru.

> ⚠️ Соискательский API hh.ru отключён 15.12.2025, поэтому отклики выполняются через **Playwright** (браузерная автоматизация). Это нарушает пользовательское соглашение hh.ru и может привести к блокировке аккаунта. Используйте на свой страх и риск, лучше с тестового аккаунта и без агрессивных интервалов.

## Возможности
- Поиск через публичный API hh.ru с фильтрами (анонимно)
- Локальный пре-фильтр: навыки, исключённые слова/компании, ЗП
- **Claude читает ваше резюме** и для каждой пред-отобранной вакансии решает, стоит ли откликаться (score 1–10, объяснение, red flags)
- Для подходящих — Claude пишет персональное сопроводительное на основе описания вакансии и резюме
- Дайджест в markdown с вердиктом, скором и письмом
- Автоотклик через сохранённую сессию браузера (Playwright)
- История: уже видел / уже откликался

## Установка

```bash
npm install
npx playwright install chromium
cp .env.example .env
```

В `.env`:
- `HH_USER_AGENT` — обязательный, ваш email
- `ANTHROPIC_API_KEY` — для Claude-судьи и генерации писем
- `RESUME_PATH` — путь к резюме (`.txt`, `.md` или `.pdf`)
- `APPLICANT_PROFILE` — короткое описание (бэкап, если резюме не задано)

Положите рядом с проектом `resume.md` (или другой формат) — Claude его кеширует и сравнивает с каждой вакансией. В `config.json` параметр `apply.minClaudeScore` (по умолчанию 7) задаёт нижний порог: вакансии со score ниже отбрасываются.

## Использование

### 1. Логин в браузере (один раз)

```bash
npm run login
```

Откроется Chromium, вручную залогиньтесь на hh.ru (вкл. 2FA, если есть). Закройте окно — сессия сохранится в `data/browser-profile/`.

### 2. Сборка дайджеста

```bash
npm start
```

Соберёт подходящие вакансии в `data/digest-YYYY-MM-DD.md` по правилам из `config.json`.

### 3. Автоотклик

```bash
npm run apply
```

Поднимет браузер на сохранённой сессии, обойдёт все вакансии последнего дайджеста, вставит сгенерированные сопроводительные и нажмёт «Откликнуться». Между откликами — рандомная пауза `PW_MIN_DELAY_MS..PW_MAX_DELAY_MS`.

## Конфигурация

`config.json` — параметры поиска и фильтра (см. предыдущий раздел README в истории, либо комментарии в файле).

`.env`:
- `HH_USER_AGENT` — обязательный User-Agent для API hh.ru
- `PW_USER_DATA_DIR` — где хранится профиль браузера
- `PW_HEADLESS` — `false` (по умолчанию) для отладки, `true` для фоновой работы
- `PW_MIN_DELAY_MS` / `PW_MAX_DELAY_MS` — диапазон пауз между откликами

## Замечания

- Селекторы hh.ru со временем меняются — если автоотклик перестал работать, посмотрите `data/app.log` и обновите селекторы в `src/apply-playwright.js` (массивы `respondSelectors`, `submitSelectors` и т.п.).
- Тесты в вакансии: по умолчанию (`PW_TEST_MODE=manual`) скрипт ставит окно браузера на передний план и ждёт ENTER в консоли — заполняете тест и отправляете отклик руками, после ENTER идёт следующая вакансия. Чтобы вернуть старое поведение, поставьте `PW_TEST_MODE=skip`. Ручной режим работает только при `PW_HEADLESS=false`.
- Лимит откликов в день у hh.ru — ~200; не превышайте.
